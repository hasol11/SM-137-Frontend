# 숙명 137+ (민원/청원 시스템 개선 프로젝트)
<!--
> **숙명 137+**는 기존 숙명여자대학교의 민원/청원 게시판을 개선하여 민원 처리 속도를 높이고, 사용자 참여를 증대시키기 위해 시작된 민원 시스템 개선 프로젝트입니다. 웹키비키(WEBKYBICKY)팀이 SOLUX 29-2 최종발표회에서 발표한 프로젝트입니다.

<br>

## 🎯 주요 문제점 및 해결 방안

### 문제점
* **비효율적인 민원 접수:** 동일한 내용의 민원이 반복적으로 게시되어 관계자의 업무가 가중되고 민원 해결의 효율성이 저하됩니다.
* **낮은 접근성:** 민원을 제출하기 위해 여러 시스템(스노위 > 민원센터)을 거쳐야 하는 비효율적인 경로를 가지고 있습니다.

### 해결 방안
* **직관적인 UI/UX:** 사용자 경험을 고려한 설계를 통해 민원 제출 과정을 더 직관적이고 간편하게 개선합니다.
* **검색 및 추천 기능:** 신속하고 정확한 민원 검색 기능과 AI 기반 추천 기능을 통해 중복 민원을 줄이고 필요한 정보에 빠르게 접근할 수 있도록 돕습니다.

<br>

## ✨ 주요 기능

### 일반 사용자 기능
* **로그인:** 숙명 Gmail 계정(`@sookmyung.ac.kr`)으로만 로그인이 가능하며, 최초 로그인 시 학번, 학과 등 추가 정보를 입력받습니다.
* **민원 조회:** 전체 민원을 카테고리, 해시태그, 진행 상태별로 필터링하고 최신순, 스크랩순, 좋아요순으로 정렬하여 조회할 수 있습니다.
* **민원 신청:** 프로그레스 바를 통해 진행 단계를 시각적으로 안내하며, 이탈 시 경고 Alert를 통해 내용이 저장되지 않음을 알려줍니다.
* **AI 해시태그 추천:** 민원 내용 작성 후, Gemini API가 내용을 분석하여 가장 연관성 높은 해시태그(최대 3개)를 자동으로 추천합니다.
* **마이페이지 기능:** 내 민원, 스크랩한 민원, 개인정보 수정 등 사용자별 맞춤 기능을 제공합니다.

### 관리자 기능
* **민원 관리 대시보드:** 접수된 모든 민원을 다양한 조건으로 검색 및 필터링하고, 민원인의 정보와 내용을 상세히 확인하며 답변을 등록하고 상태를 변경할 수 있습니다.

## 🙋‍♀️ 제 역할 (My Contribution)

이 프로젝트에서 프론트엔드 개발을 담당했으며, 다음과 같은 기능과 컴포넌트를 구현했습니다.

#### **📄 페이지 개발**
* **내 민원 페이지:** 사용자가 직접 작성한 민원 목록을 진행 상태별로 필터링하여 조회할 수 있는 페이지를 개발했습니다.
* **스크랩한 민원 페이지:** 사용자가 스크랩한 다른 사람들의 민원을 모아서 볼 수 있는 페이지를 개발했습니다.
* **개인정보 수정 페이지:** 사용자의 학번, 학과, 이름 정보를 수정하고 서버에 반영하는 기능을 구현했습니다.

#### **🧩 공통 컴포넌트 개발**
팀원들과의 재사용성을 높이기 위해 다음과 같은 공통 컴포넌트를 설계하고 개발했습니다.

* **모달(Modal) 컴포넌트:** 알림, 확인 등 다양한 상황에 맞춰 내부 콘텐츠를 유연하게 변경할 수 있도록 설계했습니다.
* **프로그레스 바(Progress Bar) 컴포넌트:** 민원 신청 단계의 진행 상황을 시각적으로 보여주는 컴포넌트를 구현했습니다.
* **퀵링크 & 서치바(Quick Links & Search Bar) 컴포넌트:** 홈 화면에서 빠른 이동과 검색을 돕는 복합 컴포넌트를 개발했습니다.

## 🚀 실행 방법 (Getting Started)

### 사전 요구사항
* Node.js `18.0.0` 이상
* `npm` 또는 `yarn`

### 1. 프로젝트 클론
```bash
git clone [https://github.com/your-username/sm137-frontend.git](https://github.com/your-username/sm137-frontend.git)
```

### 2. 의존성 패키지 설치
```bash
npm install
```

### 3. 로컬 개발 서버 실행
```bash
npm run dev
```
